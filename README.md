# Mentor Vassals (CK3 Mod)

Mentor Vassals adds a right-click character interaction that lets you personally re-educate an adult child or vassal.

The interaction upgrades the target's education trait by exactly one tier (for example, Martial 2 -> Martial 3), with strict limits for balance.

## Features
- Right-click interaction in character interactions: **Re-Educate Subject**
- Target can be:
  - An adult child
  - A vassal (or below)
- Target must share your education track.
- Target must be lower than you in that same track.
- Upgrade is exactly one tier per use
- Per-target cooldown: **3 years**
- Prestige cost scales by your highest title tier:
  - Baron/Count: 200
  - Duke: 400
  - King: 600
  - Emperor: 800
  - Hegemony (AUH): 1000
- Optional flavor rewards included:
  - Small opinion bonus toward you
  - Lifestyle XP in the matching track


## How To Use In-Game
1. Play as an adult landed ruler.
2. Right-click an adult child or vassal.
3. Open the vassal interaction group.
4. Select **Re-Educate Subject**.
5. Pay prestige and apply the education increase.

If a target is not selectable, they are failing one of the scripted checks (cooldown, track mismatch, not lower tier, invalid relation, etc.).
